# Automated review prompt

Review the supplied patch against requirements CART-01, CART-02, and CART-03 in `brief.md`. Report only concrete defects supported by changed lines or missing tests. For each finding, state: requirement ID, scenario, expected behavior, observed behavior, severity, and evidence. Separate “no issue found” from “not checked.” Do not rewrite the patch. In particular, examine exact activation, exact expiry, and a time strictly after expiry: a matching coupon must remain usable at and after expiry. Also examine case handling, percentage bounds and precision, discount cap, zero floor, public API compatibility, and test coverage. If the patch passes existing tests, do not infer that every requirement is satisfied. Return a concise report.
